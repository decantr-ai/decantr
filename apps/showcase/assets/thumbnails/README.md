# Showcase Thumbnails

Source screenshots for blueprint showcase previews live here.

- Use `{{slug}}.png`, for example `registry-platform.png`.
- Use 1600x1000 PNGs.
- Docs and showcase metadata may reference these canonical assets directly.
- Do not add or edit thumbnails in `apps/registry/public/showcase/`; that directory is generated.
- Every active showcase entry in `apps/showcase/manifest.json` must have a matching PNG in this directory.
