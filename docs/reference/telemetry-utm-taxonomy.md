# Decantr UTM Taxonomy

This page is retained for historical link compatibility. The registry handoff funnel, first-party telemetry ingest, PostHog operating dashboard, and registry signup/API-key intent tracking are retired in Decantr 3.8.

If Decantr runs a future marketing experiment, keep campaign links limited to non-sensitive UTM fields:

```text
utm_source=
utm_medium=
utm_campaign=
utm_content=
```

Do not include user emails, account names, private customer names, raw experiment notes, ad click ids, prompts, source code, file paths, or search query text.

Current docs and package links should point to `https://decantr.ai` or `https://api.decantr.ai/v1` as appropriate. They should not point users to `registry.decantr.ai`.
