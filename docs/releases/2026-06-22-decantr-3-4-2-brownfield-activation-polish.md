# Decantr 3.4.2 Brownfield Activation Polish

Decantr 3.4.2 is a scoped CLI release for first-time Brownfield clarity and day-two AI workflow habits.

## What Changed

- Generated `DECANTR.md` now tells assistants to run `decantr task <route> "<intent>"` before route edits.
- Brownfield guidance now makes the authority order explicit: existing source, accepted local law/style bridge, Essence V4, then hosted packs or registry guidance.
- CLI help and scan/adopt output make the first command choice clearer: `scan` for read-only preview, `adopt` for existing apps, `new` for greenfield, and `init` for advanced attach flows.
- `adopt` now points users toward Studio as the local visual next step without automatically launching it.
- Assistant bridge snippets now remind AI tools to load task context before route edits and report source/contract drift instead of guessing.
- Human text output now labels local-law and Project Health findings more clearly without changing report schemas.

## Package

- `@decantr/cli@3.4.2`

No verifier, MCP, Essence schema, telemetry, hosted upload, or package permission surface changed in this release.
